# Focus Widget — техническое задание

Версия: 0.2 (MVP) · Дата: 2026-10-23 · Изменения 0.2: ТЗ приведено к дизайну «Pomodoro виджет — стекло» (§3.8)

## 1. Цель

Десктопный виджет для Windows: Pomodoro-таймер, который при старте фокус-сессии включает музыку для концентрации с YouTube. Виджет маленький, всегда поверх окон, живёт в трее.

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Стек | Go + **Wails v3** (WebView2), фронтенд **Vue 3 + TypeScript + Vite** |
| Источник музыки | Официальный **YouTube IFrame Player API** (никакого yt-dlp/извлечения аудио) |
| Режим таймера | **Pomodoro**: фокус → короткий перерыв → … → длинный перерыв |
| Отображение плеера | **Два режима окна**: развёрнутый (плеер виден) и компактный (плеер скрыт, музыка на паузе) |
| Музыка на перерыве | **Настраивается**: пауза / тише / не трогать |
| Дизайн | Холст [«Pomodoro виджет — стекло»](https://claude.ai/artifact/JtgZRkDH5x32tfzBCqE12v): «стекло» — размытие фона под окном, цвет по фазе, тёмная и светлая темы (§3.8) |
| Платформа MVP | Windows 10/11 x64 (macOS/Linux — не тестируем, но не ломаем намеренно) |

### Ограничения YouTube, влияющие на дизайн
- Viewport плеера **не меньше 200×200 px**, плеер нельзя скрывать или перекрывать, пока он играет ([Required Minimum Functionality](https://developers.google.com/youtube/terms/required-minimum-functionality)). Отсюда правило: **в компактном режиме, на экране настроек и когда окно спрятано в трей, плеер YouTube всегда на паузе**. Таймер при этом идёт, а музыка продолжается, когда плеер снова виден (T10, T12). Встроенный шум и свои файлы (§3.2) — не плеер YouTube, поэтому играют и тогда (T17, T22).
- **Ничего поверх iframe плеера**: ни надписей, ни поповеров. Список жанров и громкость открываются ниже плеера (§3.4). Заглушки показываются только там, где iframe ещё нет или он убран (до первого «Старт», при ошибке).
- Плееру нужен нормальный http(s)-origin и Referer, иначе ошибка 153. Спайк T0 показал, что origin Wails `http://wails.localhost` подходит, а `http://127.0.0.1` хуже: часть видео на нём не играет ([spike-results.md](spike-results.md)).
- Видео с запрещённым встраиванием или недоступные пропускаются автоматически. На практике почти всё приходит с кодом 150.
- Реклама YouTube не блокируется и не скрывается.

## 3. Функциональные требования

### 3.1 Таймер (Pomodoro)
- Фазы: `focus`, `short_break`, `long_break`. Длительности по умолчанию 25 / 5 / 15 мин, длинный перерыв после каждых 4 завершённых фокус-сессий. Всё настраивается (1–180 мин, 2–10 сессий).
- Кнопки под таймером (слева направо):
  - **Сбросить фазу** — текущая фаза снова на полную длительность и ждёт старта; счётчик сессий не меняется. Неактивна, когда сбрасывать нечего (фаза в `idle` и ещё не начиналась).
  - Главная кнопка: **Старт** (`idle`) / **Пауза** (`running`) / **Продолжить** (`paused`).
  - **Пропустить фазу** — всегда активна, в том числе в `idle` (иначе при выключенном автостарте нельзя пропустить перерыв, не запустив его).
- **Сбросить цикл** (фокус с нуля, счётчик сессий в 0) — в настройках (§3.6) и в меню трея.
- Автостарт следующей фазы настраивается отдельно: `autoStartBreaks` (по умолчанию вкл) и `autoStartFocus` (по умолчанию выкл).
- Отображение: метка фазы, оставшееся время `MM:SS`, полоска прогресса фазы.

  | Состояние | Метка (развёрнутый) | Метка (компакт) |
  |---|---|---|
  | фокус, `idle` | Готов к фокусу · сессия N из M | Фокус · N/M |
  | фокус, `running` | Фокус · сессия N из M | Фокус · N/M |
  | любая фаза, `paused` | Пауза · фокус N из M / Пауза · перерыв | Пауза · фокус N/M |
  | короткий перерыв | Короткий перерыв | Перерыв · 5 мин |
  | длинный перерыв | Длинный перерыв | Длинный перерыв · 15 мин |

  N = `completedFocus + 1` (номер текущей или следующей сессии), M = `longBreakEvery`. На паузе время и прогресс приглушены (50% непрозрачности).
- Время считается от дедлайна по часам (`endsAt`), а не подсчётом тиков: без дрейфа и корректно после сна ПК. Если за время сна фаза закончилась, она завершается и применяются правила автостарта (уведомление один раз).
- По окончании фазы звучит короткий звук и показывается toast Windows (оба отключаются в настройках). Ровно один раз на конец фазы, в том числе после сна ПК и когда окно спрятано в трей (T11).
  - Звук — двухнотный сигнал (E5 → A5, около 0.8 с), синтезируется через Web Audio во фронтенде. Файла нет, громкость фиксированная и не зависит от музыки.
  - Toast отправляет Go, поэтому он работает и при скрытом окне. Например: «Фокус завершён · Начался короткий перерыв, 5 мин» или «Перерыв окончен · Дальше фокус, сессия 3 из 4. Нажмите «Старт», когда будете готовы». Клик по toast показывает окно.
- **Пауза при блокировке ПК** (T20, настройка `pauseOnLock`, по умолчанию вкл). Блокировка (Win+L, уход в экран блокировки) ставит на паузу идущий фокус: Go слушает `WM_WTSSESSION_CHANGE` через невидимое окно-получатель (`internal/session`). Перерыв идёт дальше — отдыхать можно и вдали от ПК; уже стоящий на паузе фокус не трогается. После разблокировки, если фокус всё ещё на той же паузе и toast включены, приходит toast «Фокус на паузе · Пока компьютер был заблокирован. Осталось N мин» с кнопкой «Продолжить» (продолжает таймер); клик по самому toast показывает окно. Музыка следует обычным правилам паузы (§3.3).

### 3.2 Музыка
- **Жанр** — именованный список источников. Источник: YouTube-плейлист (`playlist`), отдельное видео / live-стрим (`video`) или шум, который виджет генерирует сам (`noise`: `white`, `pink`, `brown`, `rain`; Web Audio, без сети, T17). Встроенный жанр «Шум» целиком из таких источников; вместо видео над ним карточка «звучит прямо из виджета».
- **Своя папка** (T22): в настройках выбирается папка с музыкой, и в конце списка жанров появляется «Мои файлы» — файлы `.mp3 .m4a .aac .ogg .oga .opus .flac .wav` из папки и её подпапок (до 5000, по пути), источник типа `file`. Папка сканируется заново при каждом запросе каталога (запуск, смена папки). Go отдаёт файлы странице по номеру из последнего скана (`/local-music/<n>`, с Range, middleware ассетов Wails) — другие пути на диске недоступны. Играет один `<audio>` во фронтенде (`lib/filePlayer.ts`): без сети, в компакте и из трея, громкость и затухания как у остальной музыки; над строкой музыки карточка «Из вашей папки». Трек, который не играется, пропускается до конца сессии. Папка пуста или пропала — ошибка «В папке нет музыки» (§3.7). Тип `file` недопустим в `genres.json`.
- **Строка музыки** под таймером: нота (индикатор: играет / не играет), название видео, подпись-кнопка «Жанр · i / n», затем кнопки **Пауза/Play музыки** (не влияет на таймер), **Громкость**, **Следующий трек**.
  - Подпись «Жанр · i / n» открывает **список жанров** (галочка у текущего). Позиция `i / n` — номер видео в плейлисте после его загрузки (`getPlaylistIndex()`, `getPlaylist().length`) или номер источника в жанре для видео-источников; пока неизвестна — показывается только имя жанра. Счётчиков в самом списке нет.
  - **Громкость** открывает поповер: кнопка mute, слайдер 0–100, текущее значение.
  - Отдельной кнопки «Следующий жанр» в окне нет: жанр выбирается из списка, «Следующий жанр» — в меню трея.
- «Следующий трек»: для плейлиста `nextVideo()`, для видео/стрима и шума — следующий источник жанра (по кругу), для своих файлов — следующий файл (случайный при перемешивании). Подсказка кнопки: «Следующее видео» / «Следующий звук» / «Следующий трек». Файл, доигравший до конца, тоже переключает на следующий.
- Перемешивание по умолчанию включено (настраивается): порядок видео в плейлистах и порядок своих файлов.
- Громкость, mute, текущий жанр и источник сохраняются между запусками. Текущий жанр — одно поле (`music.genreId`): выбор в строке музыки и в настройках меняет одно и то же.
- Ошибки плеера `2, 5, 100, 101, 150` (по T0 несуществующие и мёртвые ID тоже отдают `150`) → источник помечается битым на сессию, переключение на следующий; если битые все источники жанра — состояние ошибки (§3.7). Ошибка `153` → понятное сообщение (диагностика конфигурации).
- Каталог жанров по умолчанию встроен в бинарник. Пользователь может переопределить его файлом `genres.json` (редактирование через UI — не MVP).

### 3.3 Связь таймера и музыки
| Событие таймера | Музыка |
|---|---|
| Старт / продолжение фокуса | play, громкость восстанавливается до пользовательской |
| Пауза таймера | pause; при продолжении играет снова, **только если играла в момент паузы** |
| Фокус → перерыв | по настройке `breakBehavior`: `pause` (по умолчанию) / `duck` (громкость → `duckVolume`, по умолчанию 20%) / `continue` |
| Перерыв → фокус (автостарт) | play + восстановление громкости |
| Перерыв → фокус без автостарта (idle) | pause |
| Сбросить фазу / Сбросить цикл | pause |
| Ручная пауза музыки во время фокуса | уважается: автоматика не включает музыку до следующего явного Старт/Play |

Уточнения (T8, `frontend/src/lib/musicPolicy.ts`):
- «Фокус → перерыв» — и по истечении, и по «Пропустить», и когда перерыв ждал «Старт» и его запустили: везде применяется `breakBehavior`.
- «Перерыв → фокус» и сбросы снимают приглушение `duck`. Приглушение не меняет сохранённую громкость и никогда не делает звук громче пользовательского.
- Политика решает, нужна ли музыка (`wanted`); слышна ли она — решает плеер. Пока плеер YouTube не виден (компакт, трей, экран настроек), он стоит на паузе и продолжает, когда снова виден, если музыка всё ещё нужна; встроенный шум и свои файлы играют всегда (T17, T22). Музыку, включённую вручную при остановленном таймере, разворачивание тоже возобновляет.
- «Продолжить» не снимает ручную паузу музыки; снимают только «Старт» фокуса и кнопка Play.
- Плавность (T18): всё, что с музыкой делает таймер, плавное; что делает пользователь кнопками строки музыки — мгновенное. Конец фокуса — затухание за 2.5 с, потом пауза; пауза, сброс и пропуск таймера — короткое затухание 0.4 с; старт и продолжение — нарастание за 1.5 с с того момента, как звук пошёл (YouTube может сначала загружаться); вход в «Тише» и выход — скольжение громкости за 1.5 с. Play во время затухания возвращает громкость вверх, не останавливая музыку. Ползунок громкости срабатывает сразу, но затухание перед паузой не отменяет.

### 3.4 Окно-виджет
- Без рамки, своя шапка с областью перетаскивания, без ресайза, по умолчанию **всегда поверх** (переключатель в настройках и в трее). Углы окна и тень — системные Windows 11 (~8 px, DWM): свой радиус 16 px из макета недостижим (T0.5, T16). Включённое «поверх» виджет держит и против приложений, которые при запуске встают выше topmost-окон (Paint): при каждой смене активного окна другого приложения он заново закрепляется наверху, не забирая фокус (B2).
- **Развёрнутый режим** 380×540, отступ 12 px, вертикальный зазор 10 px, сверху вниз:
  1. шапка 36 px: точка цвета фазы + подпись «Над чем работаю» (§3.10); кнопки **Статистика** с прогрессом дня «N/M» (§3.10), **Настройки**, **Свернуть в компакт**, **Скрыть в трей**;
  2. плеер **356×204**;
  3. метка фазы (пилюля), время 76 px, полоска прогресса 260×4;
  4. строка музыки (§3.2);
  5. кнопки таймера (§3.1), прижаты к низу.
- **Плеер до первого «Старт»**: iframe ещё не создан, на его месте наша заглушка «Видео запустится вместе с фокусом». Плеер создаётся по первому «Старт» или «Play музыки» и дальше живёт до выхода (≈1 с задержки звука при первом запуске — допустимо).
- **Поповеры** (список жанров, громкость) открываются **над строкой музыки, но ниже плеера** (как в макете) и никогда не перекрывают iframe; закрываются по клику вне них, по Esc и при потере фокуса окном (клик внутри iframe YouTube до документа не доходит). Список жанров: клавиши ↑/↓/Home/End, Enter; длинный каталог прокручивается.
- **Компактный режим** 300×96: метка фазы с иконкой «музыка на паузе», время 40 px; кнопки **Пауза/Продолжить** (круглая, цвет фазы), **Пропустить**, **Развернуть**; полоска прогресса 3 px по нижнему краю. Перетаскивается за любое место, кроме кнопок. При входе музыка ставится на паузу, при выходе продолжает, если играла и идёт фокус.
- **Окно не в фокусе**: стекло остаётся (accent policy, §3.8); интерфейс приглушает вторичный текст и иконки (§3.8).
- Позиция и режим окна сохраняются. Позиция пишется через 500 мс после остановки перетаскивания, в DIP. При запуске окно создаётся скрытым и показывается, когда загрузилась страница (событие окна `WindowRuntimeReady`). Оно встаёт на сохранённое место, если на какой-нибудь рабочей области видна его шапка (не меньше 80×20 px из верхних 36 px), и целиком вдвигается в эту рабочую область, если торчит за её край (B4). Иначе окно ставится в правый нижний угол рабочей области основного монитора с отступом 16 px (`internal/placement`). `ApplicationStarted` для этого не годится: Wails создаёт окна асинхронно, и событие может прийти раньше окна (T9).
- Смена режима меняет размер, оставляя на месте стороны, ближние к краям экрана: у нижнего края окно растёт вверх, у правого — влево, и обратно возвращается на то же место. Окно целиком остаётся на экране; новая позиция сохраняется вместе с режимом (`placement.Resize`, B4). Сворачивание: сначала политика ставит музыку на паузу, потом окно сжимается. Разворачивание: окно растёт, потом музыка продолжает. Плеер в компакте скрыт, но не пересоздаётся.
- Крестик в шапке и Alt+F4 прячут окно в трей, выход — только из меню трея.

### 3.5 Трей
- Иконка, тултип с фазой и оставшимся временем в минутах, например «Focus Widget · фокус, осталось 19 мин · сегодня 3 из 8». Минуты округляются вверх, поэтому текст меняется раз в минуту и на переходах. Хвост — прогресс дня (T25): «сегодня N из M» при цели, «сегодня N помидоров» без цели (если N > 0).
- Пока фаза идёт или стоит на паузе, иконка показывает остаток (T21, `internal/trayicon`): скруглённый квадрат цвета фазы (§3.8), белая дуга от 12 часов по часовой стрелке — оставшаяся доля фазы, под ней полупрозрачная дорожка; на паузе дуга бледнее и в центре две черты паузы. Дуга квантуется на 60 шагов и перерисовывается только при смене шага, то есть не чаще раза в 1/60 фазы. Рисует Go в размер маленькой иконки системы (`SM_CXSMICON`), со сглаживанием 4×4. В `idle` — обычная иконка приложения.
- Меню: Показать/Скрыть · Старт/Пауза/Продолжить · Пропустить фазу · Следующий жанр · Сбросить цикл · Компактный режим/Развернуть · Всегда поверх ✓ · Выход. Подписи и галочка следуют за состоянием.
- Левый клик — показать/скрыть окно.
- «Компакт/Развернуть» и «Следующий жанр» выполняет фронтенд по событию `ui:command`: у него плеер и порядок «пауза → размер». Если окно было спрятано, «Компакт/Развернуть» сначала его показывает.

### 3.6 Настройки
Отдельный экран в развёрнутом режиме (кнопка в шапке; «Назад» возвращает к таймеру), с прокруткой. Изменения применяются сразу: переключатели и сегменты — по клику, числа — по Enter или уходу из поля. Числа проверяются на лету (подсказка под полем, красная рамка); невалидное значение в Go не отправляется. Экран шлёт только изменённое поле (`SettingsService.Patch`), поэтому не затирает то, что тем временем сохранили строка музыки, окно или трей. Жанр идёт через `MusicService.Select` (как в строке музыки), «Всегда поверх» — через `WindowService.SetAlwaysOnTop`. Плеер под экраном настроек не виден, поэтому музыка на это время встаёт на паузу, как в компакте (§2), и продолжается по «Назад» (T12).

| Раздел | Поля |
|---|---|

### 3.8 Визуальный стиль
Источник правды — холст [«Pomodoro виджет — стекло»](https://claude.ai/artifact/JtgZRkDH5x32tfzBCqE12v) (артборды: развёрнутый активный / не в фокусе / светлая тема, старт с выбором жанра, пауза с громкостью, настройки, ошибки, компактный режим). Значения ниже — токены для CSS.

- **Фон окна**: размытие через accent policy (`SetWindowCompositionAttribute` + `ACCENT_ENABLE_ACRYLICBLURBEHIND`, `internal/glass`, T16) под прозрачным webview + CSS-заливка на всё окно без своего радиуса. Системный Acrylic (`Windows.BackdropType = Acrylic`, T0.5) отброшен: у неактивного окна Windows заменяла его сплошным фоном, а виджет неактивен почти всегда (B1). Accent размывает и у неактивного окна, но только при нулевых полях рамки DWM, поэтому у Wails выключено повторное расширение рамки (`DisableFramelessWindowDecorations`), а углы скругляются через `DWMWA_WINDOW_CORNER_PREFERENCE` (на Windows 10 углы прямые). Цвет accent следует теме и задаёт общую светлоту стекла; Go включает стекло до показа окна, страница — при каждой смене темы (`WindowService.SetGlass`). Заливка при включённом стекле (`data-glass="on"`): тёмная `rgba(22,24,33,0.5)`, светлая `rgba(246,247,250,0.45)` — accent сам приглушает яркий фон, и приглушённый текст держит контраст ≥ 5.6:1 над белым, синим и фиолетовым (замер T16). Рамка 1 px `rgba(255,255,255,0.12)` / `rgba(20,24,40,0.10)`. Без стекла (выключены эффекты прозрачности в Windows или не удалось включить) — сплошной фон `rgb(22,24,33)` / `rgb(246,247,250)`.
- **Цвет фазы** (`accent` — кнопки, `accentText` — текст и прогресс на тёмном, `accentSoft` — пилюля):

  | Фаза | accent | accentText | accentSoft |
  |---|---|---|---|
  | Фокус | `#4C63E6` | `#AEBBFF` | `rgba(76,99,230,0.24)` |
  | Короткий перерыв | `#B5530F` | `#FFB27A` | `rgba(181,83,15,0.26)` |
  | Длинный перерыв | `#0E7C6B` | `#6FE0C8` | `rgba(14,124,107,0.28)` |

- **Текст (тёмная тема)**: основной `#F3F4F8`, время `#F6F7FB`, вторичный `#A7ACBB`, иконки `#C4C8D4`, неактивное `#6D7282`. Светлая тема: основной `#1A1C24`, вторичный `#575C6B`, иконки `#4E5363`, accentText фокуса `#3346B8`.
- **Шрифт**: Inter 400/500/600, **поставляется вместе с приложением** (OFL, без загрузки из сети); запасной — Segoe UI Variable. Цифры — `tabular-nums`.

### 3.10 Статистика, подпись и дневная цель
- **Журнал сессий** (T23): каждый фокус, доведённый до конца (истёк, а не пропущен), дописывается строкой в `%APPDATA%\FocusWidget\sessions.jsonl`: `{"end": "2026-10-28T14:25:00+04:00", "minutes": 25, "label": "Отчёт"}`. Минуты — длительность фазы, паузы не считаются. Файл только дописывается; битые строки при чтении пропускаются (и считаются в журнале приложения). Читается целиком при запуске (`internal/stats`).
- **Сводка** (`stats.Summarize`, по календарным дням в часовом поясе ПК): сегодня (помидоры, минуты), последние 7 дней по дням, итог за 7 дней, серия дней подряд хотя бы с одним фокусом (день без фокуса ещё не закончился — сегодня серию не обрывает), сегодняшние сессии. Go присылает свежую сводку событием `stats:changed` после каждой сессии; страница перечитывает её, когда окно показывается и в полночь.
- **Экран «Статистика»** (кнопка в шапке, «Назад» — к таймеру; цвета фокуса при любой фазе): «Сегодня» — число помидоров крупно, минуты, полоска цели «N из M» или «Цель на день выполнена»; «7 дней» — столбики минут фокуса по дням (сегодня ярче, высота — доля от лучшего дня; наведение на день показывает дату, помидоры и минуты в строке над графиком вместо итога), для скринридера — та же таблица; «Серия»; «Сессии сегодня» — время окончания, подпись, минуты, новые сверху. Плеер под экраном не виден — музыка на паузе, как под настройками (§2).
- **«Над чем работаю»** (T24): подпись в шапке вместо «Focus»; пустая — приглушённое «Над чем работаю?». Клик — поле ввода; Enter или уход из поля сохраняют (пробелы схлопываются, до 60 символов, одна строка), Esc отменяет. Хранится в конфиге (`timer.label`), пока её не сменят. Попадает в toast конца фокуса («Фокус завершён · Отчёт») и в журнал — та, что была в момент окончания.
- **Дневная цель** (T25, `timer.dailyGoal`, по умолчанию 8, 0 — без цели): кнопка статистики в шапке показывает «N/M» (без цели — «N») и окрашивается в цвет фазы, когда цель выполнена; прогресс есть в тултипе трея (§3.5) и на экране статистики. Фокус, которым цель достигнута (ровно M-й за день), вместо обычного toast даёт «Цель на день выполнена · M из M помидоров за сегодня. Начался короткий перерыв, 5 мин».

### 3.11 Глобальные горячие клавиши
- T26: работают в любом приложении (`RegisterHotKey` на своём потоке без окна, `internal/hotkey`). Действия: **Старт / пауза** (как пункт трея: старт, пауза или продолжение), **Показать / скрыть** окно, **Следующий трек** (`ui:command` `next-track`, его выполняет плеер). По умолчанию `Ctrl+Alt+Shift+P`, `Ctrl+Alt+Shift+F`, `Ctrl+Alt+Shift+N` — три модификатора, чтобы не отнимать сочетания у IDE.
- Сочетание — модификаторы (`Ctrl`, `Alt`, `Shift`, `Win`; нужен хотя бы Ctrl, Alt или Win) и одна клавиша: буква, цифра, F1–F12, Space, стрелки. Клавиши — по положению на клавиатуре (`KeyboardEvent.code`), поэтому сочетание не зависит от раскладки.
- В настройках: поле с сочетанием; клик — запись («Нажмите сочетание…»), Esc — отмена, Backspace/Delete или × — выключить. Пока идёт запись, виджет отпускает все свои сочетания (`HotkeyService.Suspend`), чтобы нажатое дошло до страницы. Сочетание, уже назначенное другому действию, не сохраняется («Уже у «…»»; Go тоже отвергает такие настройки). Сочетание, которое Windows не дала (занято другим приложением), подсвечивается красным с надписью «Занято другим приложением» (`hotkeys:status`); остальные работают.

**Принципы**
- Источник правды по таймеру и настройкам — Go. Плеер живёт только во фронтенде (он и есть DOM-объект YouTube).
- Политика «таймер → музыка» (3.3) — чистая функция в `musicPolicy.ts` с unit-тестами. Go ничего не знает о плеере.
- `internal/*` не импортирует Wails: таймер и конфиг тестируются обычным `go test` и переживут смену фреймворка.
- **Autoplay:** WebView2 запускается с `Options.Windows.AdditionalBrowserArgs = ["--autoplay-policy=no-user-gesture-required"]`. Без этого флага `playVideo()` со звуком без клика блокируется (T0), а значит не работают «Старт» из трея и автостарт фазы. Дополнительно по клику «Старт» фокуса фронтенд вызывает `play()` синхронно в обработчике, параллельно с `TimerService.Start()`. Для перерыва этого не делается: при `breakBehavior = pause` звук бы на миг включился.
- Цвета, размеры и шрифты — CSS-токены (§3.8); тема переключается атрибутом `data-theme` на `<html>`, «Системная» следует `prefers-color-scheme`.

### 5.1 Модель таймера

```go
type Phase  string // "focus" | "short_break" | "long_break"
type Status string // "idle" | "running" | "paused"

type State struct {
    Phase          Phase
    Status         Status
    DurationMs     int64 // полная длительность текущей фазы
    RemainingMs    int64
    CompletedFocus int   // завершённые фокусы в текущем длинном цикле
    LongBreakEvery int
}
```

Переходы:
```
idle    --Start-->       running
running --Pause-->       paused --Resume--> running
running --Expire-->      next(phase); status = running, если autoStart для следующей фазы, иначе idle
any     --Skip-->        next(phase), status = idle (CompletedFocus не увеличивается)
any     --ResetPhase-->  та же фаза, idle, полная длительность (CompletedFocus не меняется)
any     --Reset-->       focus, idle, CompletedFocus = 0          («Сбросить цикл»)

Expire фокуса увеличивает CompletedFocus.
next(focus)  = long_break, если фокус завершён (Expire) и CompletedFocus >= LongBreakEvery, иначе short_break
               (пропущенный фокус не засчитывается: после Skip всегда short_break)
next(break)  = focus; выход из long_break (Expire или Skip) обнуляет CompletedFocus
```

Сколько бы дедлайн ни был просрочен (сон ПК), тик даёт **ровно один** Expire. Автостартованная следующая фаза получает полную длительность, отсчитанную от момента пробуждения. Дедлайны сравниваются по настенным часам (`time.Now().Round(0)`), поэтому время сна всегда засчитывается.

Изменение длительностей в настройках применяется к фазам в состоянии `idle` сразу, к идущей фазе — со следующей.
