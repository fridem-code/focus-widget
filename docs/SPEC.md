# Focus Widget — техническое задание

Версия: 0.2 (MVP) · Дата: 2026-10-23 · Изменения 0.2: ТЗ приведено к дизайну «Pomodoro виджет — стекло» (§3.8)

## 1. Цель

Десктопный виджет для Windows: Pomodoro-таймер, который при старте фокус-сессии включает музыку для концентрации с YouTube. Виджет маленький, всегда поверх окон, живёт в трее.

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Стек | Go + **Wails v3** (WebView2), фронтенд **Vue 3 + TypeScript + Vite** |
| Источник музыки | Официальный **YouTube IFrame Player API** (никакого yt-dlp/извлечения аудио) |
| Режим таймера | **Pomodoro**: фокус → короткий перерыв → … → длинный перерыв |
| Отображение плеера | **Два режима окна**: развёрнутый (плеер виден) и компактный (плеер скрыт, музыка на паузе) |
| Музыка на перерыве | **Настраивается**: пауза / тише / не трогать |
| Дизайн | Холст [«Pomodoro виджет — стекло»](https://claude.ai/artifact/JtgZRkDH5x32tfzBCqE12v): «стекло» на системном Acrylic Windows 11, цвет по фазе, тёмная и светлая темы (§3.8) |
| Платформа MVP | Windows 10/11 x64 (macOS/Linux — не тестируем, но не ломаем намеренно) |

### Ограничения YouTube, влияющие на дизайн
- Viewport плеера **не меньше 200×200 px**, плеер нельзя скрывать или перекрывать, пока он играет ([Required Minimum Functionality](https://developers.google.com/youtube/terms/required-minimum-functionality)). Отсюда правило: **в компактном режиме музыка всегда на паузе**.
- **Ничего поверх iframe плеера**: ни надписей, ни поповеров. Список жанров и громкость открываются ниже плеера (§3.4). Заглушки показываются только там, где iframe ещё нет или он убран (до первого «Старт», при ошибке).
- Плееру нужен нормальный http(s)-origin и Referer, иначе ошибка 153. Спайк T0 показал, что origin Wails `http://wails.localhost` подходит, а `http://127.0.0.1` хуже: часть видео на нём не играет ([spike-results.md](spike-results.md)).
- Видео с запрещённым встраиванием или недоступные пропускаются автоматически. На практике почти всё приходит с кодом 150.
- Реклама YouTube не блокируется и не скрывается.

## 3. Функциональные требования

### 3.1 Таймер (Pomodoro)
- Фазы: `focus`, `short_break`, `long_break`. Длительности по умолчанию 25 / 5 / 15 мин, длинный перерыв после каждых 4 завершённых фокус-сессий. Всё настраивается (1–180 мин, 2–10 сессий).
- Кнопки под таймером (слева направо):
  - **Сбросить фазу** — текущая фаза снова на полную длительность и ждёт старта; счётчик сессий не меняется. Неактивна, когда сбрасывать нечего (фаза в `idle` и ещё не начиналась).
  - Главная кнопка: **Старт** (`idle`) / **Пауза** (`running`) / **Продолжить** (`paused`).
  - **Пропустить фазу** — всегда активна, в том числе в `idle` (иначе при выключенном автостарте нельзя пропустить перерыв, не запустив его).
- **Сбросить цикл** (фокус с нуля, счётчик сессий в 0) — в настройках (§3.6) и в меню трея.
- Автостарт следующей фазы настраивается отдельно: `autoStartBreaks` (по умолчанию вкл) и `autoStartFocus` (по умолчанию выкл).
- Отображение: метка фазы, оставшееся время `MM:SS`, полоска прогресса фазы.

  | Состояние | Метка (развёрнутый) | Метка (компакт) |
  |---|---|---|
  | фокус, `idle` | Готов к фокусу · сессия N из M | Фокус · N/M |
  | фокус, `running` | Фокус · сессия N из M | Фокус · N/M |
  | любая фаза, `paused` | Пауза · фокус N из M / Пауза · перерыв | Пауза · фокус N/M |
  | короткий перерыв | Короткий перерыв | Перерыв · 5 мин |
  | длинный перерыв | Длинный перерыв | Длинный перерыв · 15 мин |

  N = `completedFocus + 1` (номер текущей или следующей сессии), M = `longBreakEvery`. На паузе время и прогресс приглушены (50% непрозрачности).
- Время считается от дедлайна по часам (`endsAt`), а не подсчётом тиков: без дрейфа и корректно после сна ПК. Если за время сна фаза закончилась, она завершается и применяются правила автостарта (уведомление один раз).
- По окончании фазы звучит короткий звук и показывается toast Windows (оба отключаются в настройках).

### 3.2 Музыка
- **Жанр** — именованный список источников. Источник: YouTube-плейлист (`playlist`) или отдельное видео / live-стрим (`video`).
- **Строка музыки** под таймером: нота (индикатор: играет / не играет), название видео, подпись-кнопка «Жанр · i / n», затем кнопки **Пауза/Play музыки** (не влияет на таймер), **Громкость**, **Следующий трек**.
  - Подпись «Жанр · i / n» открывает **список жанров** (галочка у текущего). Позиция `i / n` — номер видео в плейлисте после его загрузки (`getPlaylistIndex()`, `getPlaylist().length`) или номер источника в жанре для видео-источников; пока неизвестна — показывается только имя жанра. Счётчиков в самом списке нет.
  - **Громкость** открывает поповер: кнопка mute, слайдер 0–100, текущее значение.
  - Отдельной кнопки «Следующий жанр» в окне нет: жанр выбирается из списка, «Следующий жанр» — в меню трея.
- «Следующий трек»: для плейлиста `nextVideo()`, для видео/стрима — следующий источник жанра (по кругу).
- В плейлистах по умолчанию включён shuffle (настраивается).
- Громкость, mute, текущий жанр и источник сохраняются между запусками. Текущий жанр — одно поле (`music.genreId`): выбор в строке музыки и в настройках меняет одно и то же.
- Ошибки плеера `2, 5, 100, 101, 150` (по T0 несуществующие и мёртвые ID тоже отдают `150`) → источник помечается битым на сессию, переключение на следующий; если битые все источники жанра — состояние ошибки (§3.7). Ошибка `153` → понятное сообщение (диагностика конфигурации).
- Каталог жанров по умолчанию встроен в бинарник. Пользователь может переопределить его файлом `genres.json` (редактирование через UI — не MVP).

### 3.3 Связь таймера и музыки
| Событие таймера | Музыка |
|---|---|
| Старт / продолжение фокуса | play, громкость восстанавливается до пользовательской |
| Пауза таймера | pause; при продолжении играет снова, **только если играла в момент паузы** |
| Фокус → перерыв | по настройке `breakBehavior`: `pause` (по умолчанию) / `duck` (громкость → `duckVolume`, по умолчанию 20%) / `continue` |
| Перерыв → фокус (автостарт) | play + восстановление громкости |
| Перерыв → фокус без автостарта (idle) | pause |
| Сбросить фазу / Сбросить цикл | pause |
| Ручная пауза музыки во время фокуса | уважается: автоматика не включает музыку до следующего явного Старт/Play |

Уточнения (T8, `frontend/src/lib/musicPolicy.ts`):
- «Фокус → перерыв» — и по истечении, и по «Пропустить», и когда перерыв ждал «Старт» и его запустили: везде применяется `breakBehavior`.
- «Перерыв → фокус» и сбросы снимают приглушение `duck`. Приглушение не меняет сохранённую громкость и никогда не делает звук громче пользовательского.
- В компактном режиме плеер всегда на паузе: решения «играть / не играть» запоминаются и выполняются при разворачивании, если таймер идёт.
- «Продолжить» не снимает ручную паузу музыки; снимают только «Старт» фокуса и кнопка Play.

### 3.4 Окно-виджет
- Без рамки, своя шапка с областью перетаскивания, без ресайза, по умолчанию **всегда поверх** (переключатель в настройках и в трее). Углы окна и тень — системные Windows 11 (~8 px, DWM): на Acrylic свой радиус 16 px из макета недостижим (T0.5).
- **Развёрнутый режим** 380×540, отступ 12 px, вертикальный зазор 10 px, сверху вниз:
  1. шапка 36 px: точка цвета фазы + «Focus»; кнопки **Настройки**, **Свернуть в компакт**, **Скрыть в трей**;
  2. плеер **356×204**;
  3. метка фазы (пилюля), время 76 px, полоска прогресса 260×4;
  4. строка музыки (§3.2);
  5. кнопки таймера (§3.1), прижаты к низу.
- **Плеер до первого «Старт»**: iframe ещё не создан, на его месте наша заглушка «Видео запустится вместе с фокусом». Плеер создаётся по первому «Старт» или «Play музыки» и дальше живёт до выхода (≈1 с задержки звука при первом запуске — допустимо).
- **Поповеры** (список жанров, громкость) открываются **над строкой музыки, но ниже плеера** (как в макете) и никогда не перекрывают iframe; закрываются по клику вне них, по Esc и при потере фокуса окном (клик внутри iframe YouTube до документа не доходит). Список жанров: клавиши ↑/↓/Home/End, Enter; длинный каталог прокручивается.
- **Компактный режим** 300×96: метка фазы с иконкой «музыка на паузе», время 40 px; кнопки **Пауза/Продолжить** (круглая, цвет фазы), **Пропустить**, **Развернуть**; полоска прогресса 3 px по нижнему краю. Перетаскивается за любое место, кроме кнопок. При входе музыка ставится на паузу, при выходе продолжает, если играла и идёт фокус.
- **Окно не в фокусе**: Windows сама заменяет Acrylic сплошным фоном; интерфейс приглушает вторичный текст и иконки (§3.8).
- Позиция и режим окна сохраняются. При запуске позиция проверяется на попадание в видимые мониторы, иначе окно ставится в правый нижний угол основного монитора.
- Крестик в шапке прячет окно в трей, выход — только из меню трея.

### 3.5 Трей
- Иконка, тултип с фазой и оставшимся временем (обновляется раз в минуту и на переходах).
- Меню: Показать/Скрыть · Старт/Пауза · Пропустить фазу · Следующий жанр · Сбросить цикл · Компакт/Развернуть · Всегда поверх ✓ · Выход.
- Левый клик — показать/скрыть окно.

### 3.6 Настройки
Отдельный экран в развёрнутом режиме (кнопка в шапке; «Назад» возвращает к таймеру), с прокруткой. Изменения применяются сразу.

| Раздел | Поля |
|---|---|
| Таймер | Фокус, Короткий перерыв, Длинный перерыв (мин, 1–180) · Длинный перерыв каждые N сессий (2–10) · Автостарт перерывов · Автостарт фокуса |
| Музыка | На перерыве: Пауза / Тише / Не трогать · Громкость «Тише» (0–100%, видна при «Тише») · Жанр (то же поле, что в строке музыки) · Перемешивать плейлисты |
| Уведомления | Звук в конце фазы · Уведомление Windows |
| Окно | Всегда поверх окон · Тема: Системная / Тёмная / Светлая |
| Цикл | Кнопка «Сбросить цикл · счётчик сессий в 0» |

### 3.7 Ошибки
Таймер при любых ошибках музыки продолжает работать. Вместо iframe показывается карточка 356×204, строка музыки — в состоянии ошибки (Play и «Следующий трек» неактивны).

| Ошибка | Карточка | Действие | Строка музыки |
|---|---|---|---|
| Все источники жанра недоступны | «Нет доступных видео» + пояснение | «Выбрать другой жанр» (открывает список жанров) | «Музыка недоступна» · «Жанр · 0 / n» |
| Нет сети (`navigator.onLine === false`, не грузится `iframe_api`) | «Нет подключения к интернету» | «Повторить»; при событии `online` музыка восстанавливается сама | «Ожидание сети» |
| Ошибка 153 (конфигурация плеера) | «Плеер не может загрузить видео» + код ошибки | «Повторить» | «Музыка недоступна» |

### 3.8 Визуальный стиль
Источник правды — холст [«Pomodoro виджет — стекло»](https://claude.ai/artifact/JtgZRkDH5x32tfzBCqE12v) (артборды: развёрнутый активный / не в фокусе / светлая тема, старт с выбором жанра, пауза с громкостью, настройки, ошибки, компактный режим). Значения ниже — токены для CSS.

- **Фон окна**: системный Acrylic (`BackgroundTypeTranslucent` + `Windows.BackdropType = Acrylic`, проверено в T0.5) + CSS-заливка на всё окно без своего радиуса: тёмная `rgba(22,24,33,0.72)` (в макете 0.62; на живом Acrylic поверх светлых окон 0.62 выглядит серо, подобрано в T5), светлая `rgba(246,247,250,0.80)`; рамка 1 px `rgba(255,255,255,0.12)` / `rgba(20,24,40,0.10)`. Окно не в фокусе — Windows сама заменяет Acrylic сплошным фоном (как в артборде «не в фокусе», `#1F2129`). Если Acrylic недоступен (Windows 10, отключённая прозрачность) — сплошной фон.
- **Цвет фазы** (`accent` — кнопки, `accentText` — текст и прогресс на тёмном, `accentSoft` — пилюля):

  | Фаза | accent | accentText | accentSoft |
  |---|---|---|---|
  | Фокус | `#4C63E6` | `#AEBBFF` | `rgba(76,99,230,0.24)` |
  | Короткий перерыв | `#B5530F` | `#FFB27A` | `rgba(181,83,15,0.26)` |
  | Длинный перерыв | `#0E7C6B` | `#6FE0C8` | `rgba(14,124,107,0.28)` |

- **Текст (тёмная тема)**: основной `#F3F4F8`, время `#F6F7FB`, вторичный `#A7ACBB`, иконки `#C4C8D4`, неактивное `#6D7282`. Светлая тема: основной `#1A1C24`, вторичный `#575C6B`, иконки `#4E5363`, accentText фокуса `#3346B8`.
- **Шрифт**: Inter 400/500/600, **поставляется вместе с приложением** (OFL, без загрузки из сети); запасной — Segoe UI Variable. Цифры — `tabular-nums`.
- **Размеры**: время 76 px / 600 (компакт 40 px); главная кнопка 168×48 px, пилюля (ширина фиксирована, чтобы соседние кнопки не сдвигались при смене «Пауза» ↔ «Продолжить»); круглые кнопки 44 px; иконки-кнопки 36 px; скругления: окно — системное, плеер и строки 10, поповеры 10–12, поля 6.
- Иконки — inline SVG с обводкой 1.75 px из макета.

### 3.9 Прочее
- Один экземпляр: повторный запуск показывает уже открытое окно.

## 4. Нефункциональные требования
- Размер exe ≤ 20 МБ; для WebView2 runtime используется bootstrapper Wails (на Windows 11 runtime уже есть).
- В простое без музыки CPU < 1%. С играющим плеером память определяется WebView2 + YouTube, ориентир ≤ 350 МБ.
- Холодный старт до видимого окна ≤ 2 с.
- Без телеметрии и сетевых запросов, кроме YouTube.
- Конфиг пишется атомарно (temp + rename). Битый конфиг → бэкап `config.json.bak` и дефолты, приложение не падает.
- Лог: `%APPDATA%\FocusWidget\logs\app.log` с ротацией (последние 5 файлов по 1 МБ).
- Доступность: все элементы управления — настоящие `<button>`/`<input>` с `aria-label`, контраст текста ≥ 4.5:1.

```
│ internal/catalog  жанры: embed-дефолт + override из genres.json    │
│ services/         Wails-сервисы (bindings) + эмиссия событий       │

│   SettingsService Get/Update                                       │
│   MusicService    Genres/Select/SaveVolume (только persistence)    │
│   WindowService   SetMode/SetAlwaysOnTop/сохранение позиции        │
│ app/              сборка приложения, окно, трей, single instance   │
└───────────────▲─────────────────────────────┬──────────────────────┘
       bindings │ (вызовы)                    │ events
┌───────────────┴─────────────────────────────▼──────────────────────┐
│ Frontend (Vue 3 + TS)                                              │
│ composables/useTimer         подписка на timer:*, вызовы сервиса   │
│ composables/useYouTubePlayer обёртка IFrame API, ошибки, очередь   │
│ lib/musicPolicy.ts           чистая функция: переход → действия    │
│ components/ TitleBar, PlayerPanel, TimerView, TimerControls,       │
│             MusicRow, GenreMenu, VolumePopover, CompactBar,        │
│             SettingsPanel, PlayerError                             │
└────────────────────────────────────────────────────────────────────┘
```

**Принципы**
- Источник правды по таймеру и настройкам — Go. Плеер живёт только во фронтенде (он и есть DOM-объект YouTube).
- Политика «таймер → музыка» (3.3) — чистая функция в `musicPolicy.ts` с unit-тестами. Go ничего не знает о плеере.
- `internal/*` не импортирует Wails: таймер и конфиг тестируются обычным `go test` и переживут смену фреймворка.
- **Autoplay:** WebView2 запускается с `Options.Windows.AdditionalBrowserArgs = ["--autoplay-policy=no-user-gesture-required"]`. Без этого флага `playVideo()` со звуком без клика блокируется (T0), а значит не работают «Старт» из трея и автостарт фазы. Дополнительно по клику «Старт» фокуса фронтенд вызывает `play()` синхронно в обработчике, параллельно с `TimerService.Start()`. Для перерыва этого не делается: при `breakBehavior = pause` звук бы на миг включился.
- Цвета, размеры и шрифты — CSS-токены (§3.8); тема переключается атрибутом `data-theme` на `<html>`, «Системная» следует `prefers-color-scheme`.

### 5.1 Модель таймера

```go
type Phase  string // "focus" | "short_break" | "long_break"
type Status string // "idle" | "running" | "paused"

type State struct {
    Phase          Phase
    Status         Status
    DurationMs     int64 // полная длительность текущей фазы
    RemainingMs    int64
    CompletedFocus int   // завершённые фокусы в текущем длинном цикле
    LongBreakEvery int
}
```

Переходы:
```
idle    --Start-->       running
running --Pause-->       paused --Resume--> running
running --Expire-->      next(phase); status = running, если autoStart для следующей фазы, иначе idle
any     --Skip-->        next(phase), status = idle (CompletedFocus не увеличивается)
any     --ResetPhase-->  та же фаза, idle, полная длительность (CompletedFocus не меняется)
any     --Reset-->       focus, idle, CompletedFocus = 0          («Сбросить цикл»)

Expire фокуса увеличивает CompletedFocus.
next(focus)  = long_break, если фокус завершён (Expire) и CompletedFocus >= LongBreakEvery, иначе short_break
               (пропущенный фокус не засчитывается: после Skip всегда short_break)
next(break)  = focus; выход из long_break (Expire или Skip) обнуляет CompletedFocus
```

Сколько бы дедлайн ни был просрочен (сон ПК), тик даёт **ровно один** Expire. Автостартованная следующая фаза получает полную длительность, отсчитанную от момента пробуждения. Дедлайны сравниваются по настенным часам (`time.Now().Round(0)`), поэтому время сна всегда засчитывается.

Изменение длительностей в настройках применяется к фазам в состоянии `idle` сразу, к идущей фазе — со следующей.

### 5.2 События (Go → фронтенд)
| Событие | Payload | Когда |
|---|---|---|
| `timer:state` | `State` | раз в секунду при running и на любом изменении |
| `timer:transition` | `{from: State, to: State, cause: "start"\|"pause"\|"resume"\|"expire"\|"skip"\|"reset_phase"\|"reset"}` | на каждом переходе |
| `settings:changed` | `Settings` | после `SettingsService.Update` |
| `window:mode` | `"expanded"\|"compact"` | после смены режима (в том числе из трея) |

Фронтенд применяет `musicPolicy` только по `timer:transition` и `window:mode`.

### 5.3 Хранение
`%APPDATA%\FocusWidget\config.json`:
```json
{
  "version": 1,
  "timer": {
    "focusMin": 25, "shortBreakMin": 5, "longBreakMin": 15,
    "longBreakEvery": 4, "autoStartBreaks": true, "autoStartFocus": false
  },
  "music": {
    "volume": 50, "muted": false, "shuffle": true,
    "breakBehavior": "pause", "duckVolume": 20,
    "genreId": "lofi", "sourceIndex": 0
  },
  "window": { "mode": "expanded", "alwaysOnTop": true, "theme": "system", "x": null, "y": null },
  "notify": { "sound": true, "toast": true }
}
```
`window.theme`: `system` | `dark` | `light`. Добавляется без смены версии схемы: отсутствующее поле получает значение по умолчанию.

`genres.json` (необязательный override, та же схема, что у встроенного):
```json
{
  "genres": [
    { "id": "lofi", "name": "Lo-fi",
      "sources": [ { "type": "video", "id": "<LIVE_VIDEO_ID>", "title": "lofi hip hop radio (live)" } ] },
    { "id": "ambient", "name": "Эмбиент", "sources": [ { "type": "playlist", "id": "<PLAYLIST_ID>" } ] }
  ]
}
```
Встроенный каталог (T6): Lo-fi, Эмбиент, Классика, Белый шум — 11 источников, в основном плейлисты официальных каналов (Lofi Girl, Chillhop Music, SpaceAmbient, HALIDONMUSIC). Каждый проверяется в самом IFrame-плеере на origin приложения: `scripts/catalog-check/run.ps1` (oEmbed не подходит — по мёртвому стриму он отвечает 200). ID live-стримов со временем меняются (`jfKfPfyJRdk` из первой версии ТЗ уже не работает), поэтому стримы Lofi Girl берутся через её плейлист «Radios», который канал обновляет сам. Embed `live_stream?channel=<ID>` проверен и не подходит: отдаёт ошибку 150.
