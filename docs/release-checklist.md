# Релизный чек-лист

Проверка перед выпуском (T13). Ставится установщиком `bin\focuswidget-amd64-installer.exe` (`wails3 task package`).
Отмечайте пункты и записывайте, на чём проверено.

## 1. Установка и удаление

2026-10-24 проверено на машине разработчика: Windows 11, пользователь без админ-прав, WebView2 уже установлен. Чистой системой она не считается.
- Тихая установка: 6.8 с, exit 0. Создаются exe, uninstall.exe, оба ярлыка и запись в HKCU Uninstall (версия 0.1.0, иконка). Записи в HKLM нет, у exe есть сведения о версии.
- Установка поверх запущенного виджета: процесс закрыт, exe заменён.
- После установки: окно показывается; повторный запуск завершается за 79 мс, экземпляр остаётся один; toast-активатор `LocalServer32` указывает на установленный exe.
- Тихое удаление при запущенном виджете: удалены процесс, папка, ярлыки, запись Uninstall, AppUserModelId, CLSID, `HKCU\Software\Focus Widget`, иконка toast в `%TEMP%` и кэш WebView2. `%APPDATA%\FocusWidget` остался.
- Обычное удаление с ответом «Да» на вопрос о данных: удалено то же самое плюс `%APPDATA%\FocusWidget`. Интерфейс деинсталлятора на русском.

Пункты ниже нужно пройти на чистых системах.

- [ ] Чистая **Windows 11**: установщик идёт без UAC, ставит в `%LOCALAPPDATA%\Programs\Focus Widget`, ярлыки в «Пуске» и на рабочем столе, галочка «Запустить» на последней странице запускает виджет.
- [ ] Чистая **Windows 10** (22H2): то же. Если WebView2 runtime нет, установщик ставит его через bootstrapper (нужна сеть).
- [ ] В «Приложения → Установленные» есть Focus Widget с иконкой, версией и издателем.
- [ ] Установка поверх запущенного виджета: установщик закрывает его и заменяет exe.
- [ ] Удаление при запущенном виджете: виджет закрывается, exe, ярлыки и папка установки удалены.
- [ ] Удаление убирает регистрацию toast: нет `HKCU\Software\Classes\AppUserModelId\Focus Widget`, нет `HKCU\Software\Classes\CLSID\{GUID}` (GUID — значение `CustomActivator` до удаления), нет `HKCU\Software\Focus Widget`, нет `%TEMP%\Focus Widget{GUID}.png`.
- [ ] На вопрос «Удалить также настройки и журналы?» «Нет» оставляет `%APPDATA%\FocusWidget`, «Да» удаляет. Тихое удаление (`uninstall.exe /S`) их оставляет.
- [ ] Удаляется кэш WebView2 `%APPDATA%\focuswidget.exe`.

## 2. Сценарии

- [ ] **Повторный запуск**: второй запуск ярлыка не открывает второй виджет, а показывает спрятанный в трей.
- [ ] **Сон посреди фазы**: запустить фокус, усыпить ПК на время дольше остатка фазы, разбудить. Фаза завершена один раз (один сигнал, один toast), следующая фаза ведёт себя по автостарту.
- [ ] **Два монитора**: перетащить виджет на второй монитор, перезапустить — он там же. Отключить второй монитор, запустить — виджет в правом нижнем углу основного.
- [ ] **Нет сети**: отключить сеть до старта. В плеере понятная ошибка, таймер и уведомления работают. Включить сеть — плеер оживает без перезапуска.
- [ ] **Трей**: левый клик прячет/показывает окно, пункты меню работают, иконка читается на светлой и тёмной панели задач.
- [ ] **Окно не в фокусе**: акрил сменяется ровной заливкой, текст читается.
- [ ] **Прозрачность выключена** в Windows (Параметры → Специальные возможности → Визуальные эффекты): окно непрозрачное, текст читается.
- [ ] Журнал пишется в `%APPDATA%\FocusWidget\logs\app.log`, при переполнении появляются `app.log.1`…`app.log.4` по 1 МБ.

## 3. Нефункциональные требования (SPEC §4)

Повторяемый замер: `scripts\nfr-check\run.ps1` (размер, старт, простой). Память с музыкой — вручную: запустить фокус и посмотреть суммарную память процесса и его `msedgewebview2.exe` в диспетчере задач.

Результаты 2026-10-24, Windows 11 Pro 26200, 14 ядер, 1920×1200 @125 %, release-сборка 0.1.0:

| Требование | Предел | Замер | |
|---|---|---|---|
| Размер exe | ≤ 20 МБ | 11.0 МБ | ✅ |
| Холодный старт до видимого окна | ≤ 2 с | 0.44–0.54 с; первый запуск свежесобранного exe 1.2 с | ✅ |
| CPU в простое без музыки | < 1 % | 0.01–0.03 % машины (8 процессов) | ✅ |
| Память в простое | — | 230 МБ private, 415 МБ working set | — |
| Память с играющим плеером | ориентир ≤ 350 МБ | 499 МБ private (пик 510), 793 МБ working set, 11 процессов | ❌ выше ориентира |
| Память со встроенным шумом (T17, 2026-10-25, DEV-сборка) | ориентир ≤ 350 МБ | 251–257 МБ private, 10 процессов: iframe YouTube не создаётся | ✅ |
| CPU со встроенным шумом | — | 0.13 % машины | — |
| CPU с играющим плеером | — | 3 % машины (≈ 40 % одного ядра) | — |
| Сеть только к YouTube | — | не проверено сниффером | ☐ |

Память с плеером почти целиком занимают WebView2 и YouTube: отдельный процесс для iframe youtube.com (изоляция сайтов), GPU-процесс и аудио. Отключать изоляцию сайтов, чтобы её снизить, нельзя: тогда YouTube окажется в одном процессе со страницей, у которой есть доступ к Go-биндингам.
