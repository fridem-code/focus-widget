## Порядок и зависимости

```
T0 спайк ─► T1 скелет ─┬─► T2 config ─┬─► T4 TimerService ─► T0.5 спайк Acrylic ─► T5 UI таймера ─┐
                       │              │                                     │
                       ├─► T3 timer ──┘                                     ├─► T8 политика музыки ─► T9 режимы окна ─► T10 трей ─► T13 сборка
                       │                                                    │
                       └─► T6 YouTube-плеер ─► T7 UI музыки ────────────────┘
                                                        T11 уведомления (после T4) · T12 настройки (после T2, T5)
```
T2/T3 и T6 можно делать параллельно.

**Definition of Done для каждой задачи:** код проходит `task lint` и `task test`, новая логика покрыта тестами, критерии приёмки проверены вручную в `wails3 dev`, в SPEC.md отражены изменения, если решение отклонилось от него.

- [ ] Политика музыки: правило «плеер должен быть виден» (SPEC §2) касается только YouTube — встроенный шум играет в компактном режиме, из трея и под экраном настроек
- [ ] SPEC §2, §3.2 и каталог обновлены

**Готово, когда:** «Шум» играет без сети, в компакте и из трея; iframe YouTube для него не создаётся; память с играющим шумом заметно ниже, чем с YouTube.

### T18. Плавные переходы музыки · ~0.5 дня
- [ ] Затухание за 2–3 с перед паузой в конце фокуса, нарастание после старта; переход к «Тише» и обратно — плавно
- [ ] Ручные пауза и старт пользователем — без задержки
- [ ] Работает и для YouTube, и для встроенного шума

**Готово, когда:** на переходах фаз нет резких обрывов звука; ручная пауза мгновенна.

### T19. Автозапуск с Windows · ~0.25 дня
- [ ] Переключатель «Запускать вместе с Windows» в настройках (раздел «Окно»), значение в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` — источник правды реестр, не конфиг
- [ ] При автозапуске окно не забирает фокус
- [ ] Деинсталлятор удаляет значение

**Готово, когда:** после перезагрузки виджет в трее или на экране сам; выключение переключателя и удаление программы убирают автозапуск.
