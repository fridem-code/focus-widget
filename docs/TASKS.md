# Focus Widget — задачи MVP

Ссылки вида «§3.3» ведут в [SPEC.md](SPEC.md).

## Порядок и зависимости

```
T0 спайк ─► T1 скелет ─┬─► T2 config ─┬─► T4 TimerService ─► T5 UI таймера ─┐
                       │              │                                     │
                       ├─► T3 timer ──┘                                     ├─► T8 политика музыки ─► T9 режимы окна ─► T10 трей ─► T13 сборка
                       │                                                    │
                       └─► T6 YouTube-плеер ─► T7 UI музыки ────────────────┘
                                                        T11 уведомления (после T4) · T12 настройки (после T2, T5)
```
T2/T3 и T6 можно делать параллельно.

**Definition of Done для каждой задачи:** код проходит `task lint` и `task test`, новая логика покрыта тестами, критерии приёмки проверены вручную в `wails3 dev`, в SPEC.md отражены изменения, если решение отклонилось от него.

### T9. Режимы окна и позиция · ~1 день
