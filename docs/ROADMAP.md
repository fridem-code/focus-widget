# Роадмап

Что идёт после MVP (v0.1). Версии упорядочены по пользе: сначала то, что нужно виджету каждый день, потом мотивация, своя музыка и публичный выпуск. Оценки: **S** — до полудня, **M** — около дня, **L** — несколько дней.

Ограничения прежние (SPEC §2, §4): плеер YouTube виден, пока играет; никакой телеметрии и сетевых запросов, кроме YouTube, если пользователь сам не включил иное; всё хранится локально в `%APPDATA%\FocusWidget`.

## v0.1 — MVP · ✅ готово (2026-10-24)

Pomodoro-таймер с YouTube-музыкой, компактный режим, трей, уведомления, экран настроек, установщик без админ-прав (T0–T13).

Хвосты релиза:
- [ ] баги после выпуска — раздел v0.1.1 ниже и [BUGS.md](BUGS.md);
- [ ] ручной чек-лист на чистых Windows 10/11, сон, два монитора, нет сети ([release-checklist.md](release-checklist.md));
- [ ] решение по памяти с играющим плеером: 499 МБ при ориентире 350 МБ — поднять ориентир или ждать встроенного шума из v0.2.

## v0.1.1 — Исправления · ~2–3 дня

Баги, найденные после выпуска, подробно — в [BUGS.md](BUGS.md).

| Баг | Суть | Оценка |
|---|---|---|
| [B1](BUGS.md) | Стекла не видно: системный акрил пропадает у неактивного окна, а виджет неактивен почти всегда; плюс слишком плотная тонировка. Начать со спайка «accent policy» или решить перейти на непрозрачный дизайн | M (спайк) + S–M |
| [B2](BUGS.md) | Paint при запуске перекрыл виджет с включённым «поверх». Сначала диагностика, затем повторная установка `HWND_TOPMOST` при смене активного окна | S–M |
| [B3](BUGS.md) | Ошибка WebView2 в журнале при каждом запуске | S |

**Готово, когда:** стекло видно у неактивного виджета над пёстрым фоном (или принято решение о непрозрачном дизайне); ни Paint, ни другие приложения из проверки B2 не перекрывают виджет.

## v0.2 — Виджет на каждый день · ~4 дня

Виджет живёт в трее весь день: он должен стартовать сам, не тратить фазы впустую и показывать время, не открывая окна.

| Фича | Что делает | Оценка |
|---|---|---|
| Автозапуск с Windows | Переключатель в настройках; ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, админ не нужен; деинсталлятор его убирает | S |
| Пауза при блокировке ПК | Win+L ставит фокус на паузу (`WTS_SESSION_LOCK`), после разблокировки — toast «Продолжить?». Перерыв идёт дальше: отдыхать можно и вдали от ПК | M |
| Остаток на иконке трея | Кольцо прогресса в цвете фазы прямо на иконке, перерисовка раз в минуту; минуты — в подсказке | S–M |
| Плавные переходы музыки | Затухание за 2–3 с в конце фокуса, нарастание при старте; «Тише» на перерыве тоже плавно | S |
| Встроенный шум | Белый, розовый, коричневый шум и дождь синтезируются через Web Audio, как сигнал конца фазы. Работает без сети, стартует мгновенно, без iframe YouTube экономит ~250 МБ памяти. Это не плеер YouTube, поэтому шум играет и в компактном режиме, и когда виджет спрятан в трей: таймер виден, звук идёт | M |

**Готово, когда:** после перезагрузки виджет сам в трее; блокировка посреди фокуса не съедает время; жанр «Шум» играет без интернета, в компактном режиме и из трея.

## v0.3 — Мотивация · ~3–4 дня

Видеть, сколько сделано, и работать с клавиатуры.

| Фича | Что делает | Оценка |
|---|---|---|
| Статистика | Журнал сессий `sessions.jsonl` в `%APPDATA%\FocusWidget`; экран «Статистика»: фокус-минуты сегодня и за неделю, график по дням, серия дней подряд | M |
| «Над чем работаю» | Короткая подпись к сессии под таймером; попадает в toast и в статистику | S |
| Дневная цель | «N помидоров в день»: прогресс в шапке, в трее и toast при достижении. Зависит от статистики | S |
| Глобальные горячие клавиши | Старт/пауза, показать/скрыть, следующий трек из любого приложения (`RegisterHotKey`); сочетания настраиваются, конфликт с занятыми сочетаниями показывается в настройках | M |

**Готово, когда:** за неделю работы виден график; виджетом можно управлять, не уходя из IDE.

## v0.4 — Своя музыка · ~4 дня

Не только встроенный каталог.

| Фича | Что делает | Оценка |
|---|---|---|
| Свои ссылки YouTube | Вставить ссылку на видео или плейлист в жанр прямо из интерфейса; проверка, что встраивание разрешено (ошибка 150), до сохранения; правка и удаление своих источников | M |
| Локальная папка с музыкой | Жанр «Мои файлы»: mp3/flac/ogg из выбранной папки, Go отдаёт их во WebView; перемешивание и громкость как у YouTube; работает без сети. Как и шум, играет в компактном режиме и из трея | L |

**Готово, когда:** свой плейлист добавляется за 10 секунд без правки `genres.json`; свои файлы играют без интернета и в компактном режиме.

## v1.0 — Публичный релиз · ~4 дня + сертификат

Виджет можно отдавать незнакомым людям.

| Что | Зачем | Оценка |
|---|---|---|
| CI на GitHub Actions | Lint, тесты, сборка установщика на каждый PR; релиз с установщиком по тегу `v*` | M |
| Подпись кода | Без неё SmartScreen пугает «Неизвестным издателем». Подписываются exe и установщик (`wails3 task sign`); нужен платный сертификат | S + покупка |
| Проверка обновлений | Только если пользователь включил (opt-in): раз в день запрос к GitHub Releases, toast «Вышла версия X». Зависит от CI | M |
| Английский интерфейс | Строки выносятся из кода; язык по системе или в настройках; установщик уже двуязычный | M |

**Готово, когда:** установщик с подписью скачивается с GitHub Releases, на чистой системе ставится без предупреждений, ручной чек-лист пройден.

## Не планируем

| Идея | Почему нет |
|---|---|
| Включать «Не беспокоить» Windows во время фокуса | Публичного API нет, обходные пути ломаются от обновления к обновлению |
| Spotify | Нужны OAuth и Premium, свой SDK плеера — это отдельный продукт |
| macOS и Linux | Акрил, трей, toast и установщик сделаны под Windows; переносить — пересматривать половину UI и сборку |
| Мини-плеер — третий режим окна с плеером YouTube 200×200 (F1) | Костыль ради правила YouTube о видимом плеере. Музыку при видимом таймере дают встроенный шум (v0.2) и свои файлы (v0.4): они играют и в компактном режиме |
